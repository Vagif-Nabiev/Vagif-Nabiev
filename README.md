## 👋 About Me

I'm a **Computer Engineering** graduate from Ankara, Turkey, having graduated in **July 2026**, working toward a career as a **Data Scientist**. I like taking messy, real-world data — satellite imagery, transaction logs, raw CSVs — and turning it into models and decisions that actually hold up.

- 🔭 Building end-to-end ML projects on real, unfiltered data — not tutorials
- 🛰️ Led a national-level research initiative applying deep learning to satellite imagery for earthquake damage detection
- 🌱 Currently deepening my skills in model deployment and production ML workflows
- 🎯 Goal: landing my first Data Scientist role in 2026
- 💬 Ask me about U-Net segmentation, RFM/customer segmentation, or Python
